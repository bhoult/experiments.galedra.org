Browser OS, polished by a local model

A desktop that runs in a browser tab, with windows, a shell, a virtual filesystem and nine small apps. The pi coding agent built it and then kept improving it in unattended passes, running Qwen3.8-Flash-Next on one gaming PC through Strata. Each pass read the previous one's notes, chose what to fix next, and left notes for the one after.

  1. Pass 1 · 45 minutes

    Version 01

    The first pass, stopped at its 45-minute limit. Windows that snap and maximise, a terminal, a file manager, an editor and Paint, with everything saved in the browser.

    Open version 01
  2. 26 passes · over 30 hours

    Version 27

    The same desktop after 26 passes, copied about 15 minutes into the 27th.

    • Windows snap to halves and quarters, and can be moved and tiled from the keyboard
    • The shell has pipes, redirection, aliases and history search (Ctrl+R)
    • Undo and redo in Paint, and pinch-zoom in the image viewer
    • Toolbars that fit a phone-width window, and a contrast check of both themes
    Open version 27
